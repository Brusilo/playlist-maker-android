# Checklist — Sprint 3

## Задача 1. Главный экран
- [x] Приложение запускается и отображает главный экран (MainActivity)
- [x] Экран сверстан по дизайн-макету (Figma) с использованием Compose
- [x] Все кнопки на экране (Поиск, Плейлисты, Избранное, Настройки) видны и расположены корректно
