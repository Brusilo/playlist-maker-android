# Checklist — Sprint 3

## Задача 1. Главный экран
- [ ] Приложение запускается и отображает главный экран (MainActivity).
- [ ] Экран сверстан по дизайн-макету (Figma) с использованием Compose.
- [ ] Все кнопки на экране (Поиск, Плейлисты, Избранное, Настройки) видны и расположены корректно.
- [ ] При нажатии на кнопки выводится Toast с текстом Нажата кнопка "Название кнопки".

## Задача 2. Переходы между экранами
- [ ] Созданы SettingsActivity и SearchActivity.
- [ ] Они объявлены в AndroidManifest.xml.
- [ ] В обработчиках нажатий на кнопки главного экрана убран Toast.
- [ ] При нажатии на кнопки выполняется открытие соответствующих экранов:
    - [ ] Кнопка Поиск открывает SearchActivity.
    - [ ] Кнопка Настройки открывает SettingsActivity.
- [ ] Переходы работают без падений приложения.
